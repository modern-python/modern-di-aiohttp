# Design: Canonical minimal-DI example (aiohttp rollout)

## Summary

Ship a canonical, runnable example in `modern-di-aiohttp`: a minimal
`examples/` app wiring one `Settings` (APP scope) and one `GreetingService`
(REQUEST scope) into a handler via the real `@inject` + `FromDI` idiom, an
in-memory smoke test that proves it runs, and the README `Usage example:`
line. This follows the locked pattern piloted in `modern-di-faststream`
(`planning/changes/2026-07-24.01-canonical-example-onramp.md` there).

## Motivation

The [blessed-ready on-ramp audit](https://github.com/modern-python/modern-di/blob/main/planning/audits/2026-07-22-blessed-ready-onramp-report.md)
found most integrations, aiohttp included, at D2=1 / D6=1: a complete inline
README example but no dedicated, linked canonical example — so neither the
`Usage example:` line (D6) nor a D2=2 score is reachable. faststream piloted
the fix; this change rolls the same shape into aiohttp, the repo's own
`@inject`/`Annotated[..., FromDI(...)]` idiom.

## Design

**The example** — `examples/app.py` (+ `examples/__init__.py`): the smallest
runnable aiohttp app that demonstrates the recommended wiring, matching the
README snippet's shape but as a complete, servable program:

- `Settings` — `providers.Factory(scope=Scope.APP, creator=Settings)`.
- `GreetingService` — `providers.Factory(scope=Scope.REQUEST, ...)`, depends on
  `Settings` by type (auto-injected), exposes `greet(name) -> str`.
- one `@inject`-decorated handler taking the service via
  `typing.Annotated[GreetingService, FromDI(Dependencies.service)]` — aiohttp's
  own marker idiom (an annotation, not a default value, so no `B008` applies),
  registered on `GET /greet/{name}`, wired by `setup_di(app, container)`.
- a `# Run for real: python -m examples.app ...` header comment states the
  real-run command; the `if __name__ == "__main__": web.run_app(app)` boot
  line carries a `# pragma: no cover` since the smoke test never executes it.

**Smoke test** — `tests/test_example.py`: imports the example's `app` object
and drives it with the repo's existing in-memory idiom, the `aiohttp_client`
pytest-aiohttp fixture (already used throughout `tests/`), hitting
`GET /greet/world` and asserting the real `GreetingService.greet` output in
the response body (`"Hello, world!"`).

**Coverage** — none excluded except the single unreachable `__main__` boot
line (`# pragma: no cover`, matching the faststream pattern's stated
exception for repos whose example has a real boot line). The smoke test
imports and calls the handler end to end, so the rest of `examples/app.py`
is covered under the existing `--cov-fail-under=100` gate.

**README** — insert `Usage example: [examples/](./examples)` directly under
the `Full guide` line, before `## Installation`, matching the faststream
placement. The existing inline `## Usage` snippet stays — the example is its
fuller, runnable form.

No `modern_di_aiohttp/` source changes, so no `architecture/` promotion —
this adds documentation-grade example + test, not a capability change.

## Non-goals

- A realistic/DB starter — minimal DI demo only, per the locked pattern.
- New runtime dependencies — the example uses only `aiohttp` + `modern-di`,
  already present.
- Editing the inline README snippet or any integration behavior.
- WebSocket/SESSION-scope demonstration — the existing `tests/test_websockets.py`
  already covers that idiom; the canonical example stays minimal (one HTTP
  handler).

## Testing

- `just test-ci` green: the smoke test covers `examples/app.py` to 100%
  (`__main__` line pragma-excluded) and hits a real handler asserting real
  `GreetingService` output, not a mock.
- `just lint-ci` green (ruff/ty/eof/format over the new files).
- `just check-planning` green (this bundle validates).
- Manual sanity: `python -m examples.app` starts a local server; `curl
  localhost:8080/greet/world` returns `Hello, world!`.

## Risk

- **Example rot** (low x low) — mitigated structurally: the example is
  measured (no coverage exclusion beyond the boot line) and the smoke test
  executes it every CI run, so a broken or uncovered example fails the build.
- **Example drifts from the README snippet** (low x low) — they share one
  shape; keep the example the runnable superset of the snippet.
- **Ruff version skew** (low x low) — CI floats to a newer ruff than the repo's
  pin; verified clean under both the pinned and the CI-floated version before
  merge.
